Required Documents

Application ke liye zaroori documents ki list dekhein.

Income Certificate ek zaroori document hai jo aapki family ki annual income prove karta hai. Ye scholarship, sarkari yojana, aur reservation jaise kaamon ke liye use hota hai. Bihar mein ye certificate RTPS (Right to Public Service) Bihar portal se online apply kiya ja sakta hai — bilkul free, koi fees nahi lagti.

📋 Zaroori Documents

  • Aadhaar Card
  • Residence Proof (Ration Card / Voter ID / Electricity Bill)
  • Passport size Photo
  • Mobile Number aur Email ID (OTP verification ke liye)
  • Self-declaration form (portal par available hota hai)

📝 Online Apply Karne Ka Process

  1. Official RTPS Bihar website kholein: serviceonline.bihar.gov.in
  2. Homepage par "Apply Online" option par click karein.
  3. Left sidebar ya menu mein "RTPS Services" select karein, fir "General Administration Department" choose karein.
  4. List mein se "Issuance of Income Certificate" (आय प्रमाण पत्र निर्गमन) select karein.
  5. Apna level choose karein — Block (अंचल), Sub-Division, ya District level.
  6. Application form mein apna naam, father/mother/husband ka naam, gender, address, mobile number, district, subdivision aur village bharen.
  7. Zaroori documents upload karein aur form submit kar dein.
  8. Submit karne ke baad aapko ek Application Reference Number milega — isse aap apne mobile par SMS mein bhi paayenge. Ise sambhal kar rakhein.

📥 Certificate Download Kaise Karein

Application process hone ke baad (usually kuch dinon mein), aap serviceonline.bihar.gov.in par jaakar "Download Certificate" option se, apna Application Reference Number aur naam daal kar apna certificate download kar sakte hain.

⚠️ Important Baatein

  • Ye service 100% free hai — koi bhi agent ya website agar paise maange to sambhal kar rahein, ye scam ho sakta hai.
  • Apni details bharte waqt sahi jaankari dein, galat information se application reject ho sakta hai.
  • Application Reference Number kisi ke saath share na karein.
